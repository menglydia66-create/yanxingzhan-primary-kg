# 讲法规范：名师式讲法（自写版）

> 目标：孩子一听就懂，家长照着念也能讲。
> 「名师式」指的是好老师常用的讲课**方法**：从具体到抽象、先懂后练、错误对照、分步搭台阶。**不是**照搬或冒用任何具体老师的讲稿、视频或书。全部内容自写；仓库和对外文案里**不出现**「名师」「某某老师讲法」之类的字样（校验器会拦）。

## 一、讲法五件套（每个知识点必须齐全）

| # | 环节 | 写什么 | 字段 | 要求 |
|---|---|---|---|---|
| ① | **生活场景 / 实物 / 画图引入** | 孩子身边能看到、摸到、画出来的东西 | `explain.scene` | 1–2 句；家里就能做；不用课本插图、不用课本情境 |
| ② | **一句话讲透本质** | 这个知识点到底在说什么 | `essence` | ≤60 字；只用孩子听得懂的词；不用术语堆叠 |
| ③ | **口诀或类比** | 帮助记忆的一句话 | `explain.hook` | 口诀必须**自编**；不照搬民间流传口诀、教辅书或网课里的口诀；类比要贴近孩子生活 |
| ④ | **一步一步小台阶** | 孩子照着做就能做对的步骤 | `explain.steps` | 2–5 步；每步一个动作；动词开头（看、找、数、写、读） |
| ⑤ | **最常见错误对照** | 错的样子 / 对的样子 / 为什么 | `explain.mistake` | 只写**一个**最常见的错；"为什么"要讲到根上，不能只说"粗心" |

另外三项：
- `pitfalls` 易错点提示：1–3 条，只提示，不配题（配套题目属于收费体系）。
- `mastery` 掌握标准：2–4 条，以「能……」开头，必须是看得见的行为（能说出、能写出、能摆出），不写「理解」「掌握」这类看不见的词。
- `parent_check` 家长随口问一句：家长不用会讲，问这一句就能看出孩子懂没懂。只用口头问，不布置书面任务，也不是检查或批改作业。用家里的场景提问，让孩子**说出过程**，而不是只报答案。

- `oral_diagnosis` 口头诊断卡（v0.2 起必填）：`questions` 1–3 条，每条含 `ask` / `pass` / `misconception`；另有 `fallback` 退步说明。一、二年级只口头或游戏。`parent_check` 与第一问的 `ask` 保持一致。
- `textbook_refs[].verification`：已核-官方 / 已核-双源 / 已核-单源 / 待核对。查不到写「待核对」，不许猜。


## 二、用词与长度

- **用词**：1–2 年级按「孩子读给自己听也懂」的标准写；3–6 年级可以用课本里已经出现过的术语，但第一次出现时要用一句白话解释。
- **长度**：讲解（scene + hook + steps + example + mistake）建议 ≤320 字，**上限 400 字**（校验器会拦）。写不下，说明知识点切得太大，应该拆开。
- **句子**：一句话只说一件事；少用「的的的」；数字、符号用全角或规范写法（＋ － ＝ ＞ ＜）。
- **语气**：平实，不夸张；不写「超简单」「秒懂」「一招搞定」。

## 三、知识点怎么切

- 一个知识点 = 一个能**单独讲清**、**单独诊断**的小点。判断方法：能不能用一句「家长随口问一句」测出来？测不出来就是太大了。
- 名称用自写概括，不用课文标题或例题标题当名字。
- 同学科不能重名。归一化之后（去掉空格和标点）相同也算重名，校验器会拦。跨年级的同一主题用「（20以内）」「（万以内）」这类范围词区分，或者合并成一个点，再挂多个教材位置。

## 四、前置关系怎么定

- `必需`：不会它，后面就学不会。`有帮助`：会了更容易，不会也能学。
- 每条边写一句原因（≤50 字）。
- **不能倒序**：必需前置在教材里出现的位置（年级 → 册 → 单元）不能比后续知识点更晚。如果课本顺序确实是倒过来的，就改成「有帮助」，并在 reason 里写明。
- **不能成环**，也**不能重复**。

## 五、难度定档（difficulty_level，D1–D5）

难度**与年级无关**，只看「沿必需前置往回走，最长要走几步」（必需前置深度）：

| 必需前置深度 | 档位 | 大致含义 |
|---|---|---|
| 0 | D1 起步 | 不需要先会别的，靠生活经验就能懂 |
| 1 | D2 基础 | 需要先会 1 层前置 |
| 2–3 | D3 进阶 | 需要多层前置或两步以上操作 |
| 4–6 | D4 综合 | 建立在一条较长的前置链上，或要把几条链合起来用 |
| ≥7 | D5 深化 | 校内同主题里最靠后、最综合的部分（仍在课标范围内） |

- 校验器按上表算出建议档位（`--fix-levels` 可以自动回填）。
- 人工可以调 **±1 档**，但必须写 `difficulty_note` 说明原因；调完后后续知识点的档位不能低于它的必需前置（不能倒挂）。
- 全量图谱补齐后，深度会随前置链变长而增加，档位要重新计算一次（重跑 `--fix-levels` 前，先把人工调过档的点列出来复核）。

## 六、主题链（topic_chain）

- 把跨年级、跨册的同一主题串起来，例如数学「数的认识」：1～5 → 0 → 11～20 → 100以内 → 万以内 → 大数 → 分数初步 → 小数。
- `step` 用 10、20、30 编号并留空位，后面插入新知识点时不用改旧编号。
- 同一条链内，必需前置的 step 必须更小。

## 七、红线（校验器会自动拦下其中能检测的部分）

- 不搬教材原文、原题、插图、课文对话；不用教材人物名（英语例句用自编人名）。
- 不照搬或冒用任何具体老师、机构的讲稿、视频、书和口诀；不写「名师」「特级教师」「教龄」「一线教师」。
- 只做校内：不写竞赛、奥数、超前学、抢跑；讲解深度不超过对应年级的课标要求。
- 不写提分、押题、必考、保过、秒杀、满分。
- 不放二维码、联系方式、价格、报名和领取入口；不推荐课程或账号；不写「关注」「私信」「评论区」「完整版见」之类的诱导或导流语（开源项目本身不引流）。
- 不从任何第三方知识图谱（包括 ODbL / CC BY-SA / CC BY-NC 授权的）复制或翻译数据和文字。

## 八、范例

见 [MA-1A-012 凑十法：9加几](../docs/知识点/math/MA-1A-012.md)，五件套齐全：
- 场景：差一格就满的 10 格盒子
- 本质：先凑成一个十，再加剩下的
- 类比：差一个就满的盒子，先把它装满
- 小台阶：看差几 → 拆小数 → 凑十 → 加剩下的
- 错误对照：9＋5＝10＋5（忘了 5 已经给出去 1 个）
