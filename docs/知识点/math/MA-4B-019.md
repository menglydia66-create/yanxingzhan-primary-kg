## 怎么讲孩子容易懂
**① 从生活里引入：** 0.30 元和 0.3 元都是 3 角；尺子上 0.50 米与 0.5 米同一刻度。

**② 一句话本质：** 小数末尾添 0 或去掉 0，小数大小不变；小数点位置不动。

**③ 口诀 / 类比：** 末尾的 0 可添可去，大小照旧。

**④ 一步一步来：**
1. 写出末尾带 0 的小数
2. 去掉末尾 0
3. 再添回 0 对照
4. 强调小数点没移动

**⑤ 最常见的错：**

| 常见想法 | 可以怎样 | 为什么 |
|---|---|---|
| 把中间的 0 也删掉 | 只能动末尾的 0，中间 0 占位不能随便删 | 末尾 0 不影响大小，中间 0 影响数位 |

## 易错点提示
- 0.30 变成 3.0
- 与四舍五入混淆

## 怎样算学会了（掌握标准）
- 能判断末尾添去 0 后是否相等
- 能化简小数末尾 0
- 能说明大小不变的原因

## 口头诊断卡（了解懂没懂，不是考试）

一次一问，让孩子说出来。答完再问「你怎么想的」。

**问 1：** 0.80 和 0.8 相等吗？0.08 和 0.8 呢？
- 通过：能说前一对相等、后一对不等并说明
- 典型误概念：两对都说相等

**问 2：** 为什么末尾可以添 0，小数点却不能随便移？
- 通过：能说到添 0 不改变数位上的数，移动小数点会改大小
- 典型误概念：说都一样

**退步：** 退到：先会小数读写；再用钱币只比末尾 0。
