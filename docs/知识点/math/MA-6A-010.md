## 怎么讲孩子容易懂
**① 从生活里引入：** 2/3 与 3/2 的积是 1，所以它们互为倒数。

**② 一句话本质：** 乘积是 1 的两个数互为倒数；求分数倒数可交换分子分母；0 没有倒数。

**③ 口诀 / 类比：** 乘起来得 1，就互为倒数。

**④ 一步一步来：**
1. 确认乘积是否为 1
2. 分数交换分子分母求倒数
3. 整数看作分母为 1 再交换
4. 指出 0 不能求倒数

**⑤ 最常见的错：**

| 常见想法 | 可以怎样 | 为什么 |
|---|---|---|
| 说 2 的倒数是 2 | 2 的倒数是 1/2 | 互为倒数强调成对关系 |

## 易错点提示
- 带分数忘了化假分数再求
- 把「互为」说成单方面「是倒数」却不指对象

## 怎样算学会了（掌握标准）
- 能判断两数是否互为倒数
- 能求出常见数的倒数
- 能说明 0 为什么没有倒数

## 口头诊断卡（了解懂没懂，不是考试）

一次一问，让孩子说出来。答完再问「你怎么想的」。

**问 1：** 3/4 的倒数是多少？怎样想？
- 通过：能说 4/3，并提到乘积为 1 或交换分子分母
- 典型误概念：说还是 3/4

**问 2：** 为什么说 0 没有倒数？
- 通过：能提到 0 乘任何数都得 0，不能得 1，或分母不能为 0
- 典型误概念：说 0 的倒数是 0
