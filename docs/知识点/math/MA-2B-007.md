# 进一法与去尾法｜数学小学知识点讲解

> **一句话讲透：** 看问题要不要“多准备一份”或“去掉不够的一份”。

## 怎么讲孩子容易懂
**① 从生活里引入：** 25人坐车，每车限坐4人。25÷4＝6……1，还要多一辆，共7辆。

**② 一句话本质：** 看问题要不要“多准备一份”或“去掉不够的一份”。

**③ 口诀 / 类比：** 剩下的人不能扔在路上——有时要进一；有时多出来的不够一份就去掉。

**④ 一步一步来：**
1. 先算出商和余数
2. 读题：多出来的要不要再占一份
3. 要就商加1（进一）
4. 不要就把不够的去掉（去尾）

**⑤ 最常见的错：**

| 常见想法 | 可以怎样 | 为什么 |
|---|---|---|
| 有余数仍只答商6辆车 | 人没坐完要再加1辆，答7 | 余下的人也需要座位 |

## 易错点提示
- 不读题就进一或去尾
- 两种方法乱用

## 怎样算学会了（掌握标准）
- 能判断用进一还是去尾
- 能结合余数说明理由
- 能避免只报商不管实际

## 口头诊断卡（了解懂没懂，不是考试）

一次一问，让孩子说出来。答完再问「你怎么想的」。

**问 1：** 23个面包，每袋装5个，要装完至少几袋？为什么？
- 通过：能算4……3，并说明要进一成5袋
- 典型误概念：只答4袋

**问 2：** 若问“能装满几袋”，答案怎么变？
- 通过：能改成去尾答4袋并说明
- 典型误概念：两种问法答一样

**退步：** 退到：先算准有余数除法；再用“装车/装袋”对照两种问法。
