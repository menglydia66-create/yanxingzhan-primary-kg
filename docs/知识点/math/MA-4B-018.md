## 怎么讲孩子容易懂
**① 从生活里引入：** 看见 10.08：整数部分读「十」，点，再读「零八」。

**② 一句话本质：** 整数部分按整数读，小数点读作「点」，小数部分顺次读出各位数字。

**③ 口诀 / 类比：** 整数照旧读，点后一位一位读。

**④ 一步一步来：**
1. 分开整数部分与小数部分
2. 读整数部分
3. 读「点」
4. 顺次读小数部分各位

**⑤ 最常见的错：**

| 常见想法 | 可以怎样 | 为什么 |
|---|---|---|
| 把 10.08 读成十点八 | 小数部分每个数字都要读到，包括中间的 0 | 小数部分按位读数字 |

## 易错点提示
- 末尾 0 读法与性质混淆
- 漏读小数点

## 怎样算学会了（掌握标准）
- 能正确读出小数
- 能按读法写出小数
- 能对照数位表检查

## 口头诊断卡（了解懂没懂，不是考试）

一次一问，让孩子说出来。答完再问「你怎么想的」。

**问 1：** 3.04 怎么读？中间的 0 读不读？
- 通过：能读三点零四，并说明要读 0
- 典型误概念：读成三点四

**问 2：** 听到「十二点零五」写作什么？
- 通过：能写 12.05
- 典型误概念：写成 12.5

**退步：** 退到：先会小数意义；再只练一位小数读写。
