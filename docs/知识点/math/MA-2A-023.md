# 7的乘法口诀｜数学小学知识点讲解

> **一句话讲透：** 7的口诀记几个7；七七四十九等要专项练熟。

- 难度档：D5　主题链：表内乘法（第 80 步）

## 怎么讲孩子容易懂
**① 从生活里引入：** 七七四十九：7个7。可用7＋7＋…或已知6的口诀再加一个7来核对。

**② 一句话本质：** 7的口诀记几个7；七七四十九等要专项练熟。

**③ 口诀 / 类比：** 7的口诀是表内乘法后半段的一块砖。

**④ 一步一步来：**
1. 按顺序记一七到七九
2. 难句多念：六七、七七、七八
3. 抽背
4. 写几道7×几对照口诀

**⑤ 最常见的错：**

| 常见想法 | 可以怎样 | 为什么 |
|---|---|---|
| 七八五十六记成四十九 | 七八五十六 | 不要和七七四十九混淆 |

## 易错点提示
- 七八、七九背串
- 只会顺背不会用

## 怎样算学会了（掌握标准）
- 能背出7的乘法口诀
- 能口算7×1到7×9
- 能用口诀支持后续求商

## 口头诊断卡（了解懂没懂，不是考试）

一次一问，让孩子说出来。答完再问「你怎么想的」。

**问 1：** 七×六等于几？口诀？
- 通过：六七四十二
- 典型误概念：得数错

**问 2：** 七七四十九表示几个几？
- 通过：7个7
- 典型误概念：说不清

**退步：** 退到：连加几个7，再贴口诀。
