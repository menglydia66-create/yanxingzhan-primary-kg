## 怎么讲孩子容易懂
**① 从生活里引入：** 算 0.25×0.4：位数 2+1=3，整数乘得 100，前面补 0 写成 0.100。

**② 一句话本质：** 积的小数位数通常等于两个因数小数位数的和；末尾 0 可省略但不改大小。

**③ 口诀 / 类比：** 位数先加好，点完再看要不要省 0。

**④ 一步一步来：**
1. 数清每个因数小数位
2. 相加得积应有位数
3. 点完后看末尾 0
4. 决定是否简写

**⑤ 最常见的错：**

| 常见想法 | 可以怎样 | 为什么 |
|---|---|---|
| 以为积的位数等于较长的那个因数 | 一般是两位数位相加，不是取较长者 | 每位小数都表示再细一档的十分之几 |

## 易错点提示
- 忽略整数因数算 0 位
- 简写后以为位数变了意义也变

## 怎样算学会了（掌握标准）
- 能根据因数预估积的位数
- 能解释末尾 0 省略
- 能发现位数不够时前面补 0

## 口头诊断卡（了解懂没懂，不是考试）

一次一问，让孩子说出来。答完再问「你怎么想的」。

**问 1：** 0.25×0.4，积一般要点几位小数？为什么？
- 通过：能说 3 位，并说到 2+1
- 典型误概念：说 2 位

**问 2：** 0.5×0.2＝0.10，写成 0.1 后，原来的位数规则还成立吗？
- 通过：能说成立，只是末尾 0 省略
- 典型误概念：说写成 0.1 就错了

**退步：** 退到：先会小数乘小数笔算；再专门练「先加位数再点点」。
