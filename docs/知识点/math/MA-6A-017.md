## 怎么讲孩子容易懂
**① 从生活里引入：** 数轴：… −2、−1、0、1、2 …；−3 在 −1 左边，所以 −3＜−1。

**② 一句话本质：** 整数里出现负号后，数轴上 0 的左侧是负数；读作「负几」，比较大小要看位置。

**③ 口诀 / 类比：** 数轴越靠右越大。

**④ 一步一步来：**
1. 认识负号
2. 在数轴上找 0
3. 向左标负数、向右标正数
4. 靠右大靠左小来比较

**⑤ 最常见的错：**

| 常见想法 | 可以怎样 | 为什么 |
|---|---|---|
| 以为 −8＞−3，因为 8＞3 | −8 更靠左，所以 −8＜−3 | 负数比较要看数轴位置，不能只看绝对值 |

## 易错点提示
- 把负号当减号运算混淆
- 读写「负」字漏掉

## 怎样算学会了（掌握标准）
- 能读写简单负数
- 能在数轴上标出正负数与 0
- 能比较两个简单负数的大小

## 口头诊断卡（了解懂没懂，不是考试）

一次一问，让孩子说出来。答完再问「你怎么想的」。

**问 1：** −5 和 −2 谁大？你怎么想？
- 通过：能说 −2 大，并提到更靠近 0 或更靠右
- 典型误概念：说 −5 大

**问 2：** 0 是正数还是负数？
- 通过：能说 0 既不是正数也不是负数
- 典型误概念：说 0 是正数或负数
