## 怎么讲孩子容易懂
**① 从生活里引入：** 盘子里有1个苹果，吃掉了，盘子里一个也没有了，就用0表示。

**② 一句话本质：** 0表示一个也没有；在尺子上，0是起点。

**③ 口诀 / 类比：** 0像空盘子；在尺子上，0是起跑线。

**④ 一步一步来：**
1. 看着空盘子说“0个”
2. 在尺子上找到0，它排在1的前面
3. 试一试：3－3＝0，3＋0＝3

**⑤ 最常见的错：**

| 常见想法 | 可以怎样 | 为什么 |
|---|---|---|
| 3＋0＝0 | 3＋0＝3 | 加 0 就是什么也没加，还是原来的数 |

## 易错点提示
- 以为0不是数
- 0写得像6或写成一个小点

## 怎样算学会了（掌握标准）
- 能说出 0 表示一个也没有
- 能把 0 放进数的顺序里（0 在 1 前面）
- 能用空盘子说明 3－3＝0、3＋0＝3 是什么意思

## 口头诊断卡（了解懂没懂，不是考试）

一次一问，让孩子说出来。答完再问「你怎么想的」。

**问 1：** 你有 3 颗糖，我给你 0 颗，你现在有几颗？为什么？
- 通过：说出还是 3，因为一颗也没给
- 典型误概念：觉得加 0 就变成 0

**问 2：** 盘子里原来有 2 个，都吃完了，盘子里用哪个数表示？
- 通过：说出 0，表示一个也没有
- 典型误概念：以为 0 不是数，或不会说

**退步：** 退到：一起看空盘子，只说「一个也没有」；暂不写算式。
