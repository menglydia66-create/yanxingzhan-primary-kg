## 怎么讲孩子容易懂
**① 从生活里引入：** 3.6 元平均分给 2 人：3.6÷2。先除整数部分，小数点落下，再除小数部分。

**② 一句话本质：** 除数是整数时，按整数除法除，商的小数点与被除数的小数点对齐。

**③ 口诀 / 类比：** 除数是整数，商的点跟着被除数落下。

**④ 一步一步来：**
1. 按整数除法写竖式
2. 商的小数点与被除数对齐
3. 不够除商 0 或补 0 继续
4. 验算用商×除数

**⑤ 最常见的错：**

| 常见想法 | 可以怎样 | 为什么 |
|---|---|---|
| 小数点对不齐，点在商的末尾随意位置 | 商的小数点要与被除数小数点对齐 | 同一数位上的数才能相除比较 |

## 易错点提示
- 余数漏写 0
- 中途丢小数点

## 怎样算学会了（掌握标准）
- 能笔算小数÷整数
- 能说明商的小数点位置
- 能处理不够除时补 0 继续除

## 口头诊断卡（了解懂没懂，不是考试）

一次一问，让孩子说出来。答完再问「你怎么想的」。

**问 1：** 4.8÷3 商是多少？竖式里小数点写在哪？
- 通过：能说 1.6，并指出与被除数小数点对齐
- 典型误概念：说 16 或 0.16

**问 2：** 0.8÷4，被除数比除数小，怎么办？
- 通过：能说到在小数点后补算或商 0 点几
- 典型误概念：说除不尽就算了

**退步：** 退到：先会整数除法与小数乘整数；再练一位小数÷一位整数。
