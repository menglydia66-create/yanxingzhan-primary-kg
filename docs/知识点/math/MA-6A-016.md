## 怎么讲孩子容易懂
**① 从生活里引入：** 气温 0℃以下记作 −5℃；地下一层常记 B1 或 −1 层。

**② 一句话本质：** 温度低于 0℃、地下楼层、反向收支等情境里，需要用带负号的数来记录「相反意义」。

**③ 口诀 / 类比：** 往反方向走，就用负号记。

**④ 一步一步来：**
1. 找出相反意义的量
2. 约定正方向
3. 反方向用负号
4. 读出生活含义

**⑤ 最常见的错：**

| 常见想法 | 可以怎样 | 为什么 |
|---|---|---|
| 把「还剩 0 个」说成负数 | 0 表示没有，负数表示相反方向的量 | 负数不是「没有」，而是反向 |

## 易错点提示
- 负号漏读
- 把名次、编号误当负数

## 怎样算学会了（掌握标准）
- 能举出至少一个生活中的负数例子
- 能说明正负表示相反方向或意义
- 能区分「没有」与「负数」

## 口头诊断卡（了解懂没懂，不是考试）

一次一问，让孩子说出来。答完再问「你怎么想的」。

**问 1：** 电梯显示 −1，大概表示什么？
- 通过：能说到地下一层或类似含义
- 典型误概念：说少了一层就没有了

**问 2：** 零下 3 度和 3 度，哪个更冷？怎样用正负数说？
- 通过：能比较并提到 −3℃
- 典型误概念：说 3 度更冷

**退步：** 退到：先复习整数大小与计数（MA-4A-005）；再收集家里温度计、电梯楼层等例子。
