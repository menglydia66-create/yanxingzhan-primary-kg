## 怎么讲孩子容易懂
**① 从生活里引入：** 口袋里没有糖再「乘」几份还是没有；把糖分给 0 个人说不通。

**② 一句话本质：** 一个数加0得原数；减0得原数；乘0得0；0除以非0得0；任何数不能做除数0。

**③ 口诀 / 类比：** 加减速零照旧，乘零变零，除数不能是零。

**④ 一步一步来：**
1. 写出加减乘含0的结果
2. 指出0作除数无意义
3. 用生活例子解释
4. 对照算式检查

**⑤ 最常见的错：**

| 常见想法 | 可以怎样 | 为什么 |
|---|---|---|
| 写成 8÷0＝0 或 8÷0＝8 | 0不能做除数，这个算式没有意义 | 除法是分成若干份，份数不能是0 |

## 易错点提示
- 0×a 写成 a
- 0＋a 写成 0

## 怎样算学会了（掌握标准）
- 能正确计算含0的加减乘
- 能说出0不能做除数
- 能解释乘0得0

## 口头诊断卡（了解懂没懂，不是考试）

一次一问，让孩子说出来。答完再问「你怎么想的」。

**问 1：** 5×0 等于几？0÷5 等于几？5÷0 呢？
- 通过：能说 0、0、不能算/无意义
- 典型误概念：三个都报同一个数

**问 2：** 为什么不能用 0 去除一个数？你怎么跟同学解释？
- 通过：能说到没法分成 0 份或没有意义
- 典型误概念：说老师不让就算了

**退步：** 退到：先会乘除意义；再只练加0减0乘0。
