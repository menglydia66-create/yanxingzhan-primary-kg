## 怎么讲孩子容易懂
**① 从生活里引入：** 瓷砖边长 0.8 米，宽 0.5 米：0.8×0.5。可先 8×5=40，再一共 2 位小数得 0.40。

**② 一句话本质：** 小数乘小数：先按整数乘，再把两个因数的小数位数相加，给积点小数点。

**③ 口诀 / 类比：** 两位小数相加，积点两位。

**④ 一步一步来：**
1. 去掉小数点当整数乘
2. 算得整数积
3. 把两位小数位数相加
4. 从右往左数位点小数点

**⑤ 最常见的错：**

| 常见想法 | 可以怎样 | 为什么 |
|---|---|---|
| 0.8×0.5 点成 4.0 或 40 | 1+1=2 位，积是 0.40，写作 0.4 也可以 | 位数不够要在前面补 0 |

## 易错点提示
- 只数一个因数的位数
- 补 0 方向错

## 怎样算学会了（掌握标准）
- 能笔算小数×小数
- 能说明位数相加规则
- 能处理积末尾 0

## 口头诊断卡（了解懂没懂，不是考试）

一次一问，让孩子说出来。答完再问「你怎么想的」。

**问 1：** 0.3×0.4 积的小数点怎么点？等于多少？
- 通过：能说两位小数，得 0.12
- 典型误概念：说 1.2 或 12

**问 2：** 1.2×0.5 和 12×5 算完后，小数点差在哪？
- 通过：能说到因数小数位数总和不同
- 典型误概念：说得数一样

**退步：** 退到：先会小数乘整数；再练两位一位小数相乘。
