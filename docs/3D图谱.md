# 3D 知识图谱（可交互）

打开可旋转、缩放、点击的人教版小学数学 **376** 知识点 3D 依赖图：

**[打开 3D 图谱](https://menglydia66-create.github.io/yanxingzhan-primary-kg/viz/)**

## 怎么用

- **拖动**：旋转视角
- **滚轮 / 双指捏合**：缩放
- **点击节点**：看名称、年级、前置边数量；可跳到 GitHub 上的知识点 Markdown 页
- **自转**：右下角可开关缓慢自转；点「回到总览」拉远到全图

颜色按年级区分（见页面左下角图例）。边表示知识点之间的前置依赖。

## 说明

- 数据来自本仓库 `data/math/` 中的人教版知识点与依赖边，不是演示假数据。
- 页面源码在 [`viz/`](../viz/)，本地可直接用浏览器打开 `viz/index.html`（需能加载同目录的 `graph_data.json` 与 `vendor/`）。
