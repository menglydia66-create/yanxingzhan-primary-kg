# 研星站小学数学知识图谱 · 国内静态站部署说明

本目录是**纯静态站点**（HTML + JSON + 本地 JS），可直接拖到国内静态托管。  
**不要**再依赖 GitHub Pages / jsDelivr / 其它境外 CDN——3D 所需脚本已在 `viz/vendor/`。

出品：研星站｜免费开源｜不承诺提分

## 目录结构

```
yanxingzhan-kg/
  index.html          # 家长落地页
  guide.html          # 怎么用 4 步 + 3 张样例卡
  docs/按教材查.html   # 人教 376 点目录（按册/单元）
  viz/
    index.html        # 可交互 3D
    graph_data.json   # 376 点 + 依赖边
    vendor/           # three / 3d-force-graph / spritetext（本地）
  README-部署.md      # 本说明
```

## 重要：必须用 https 打开

3D 页通过 `fetch('./graph_data.json')` 加载数据。  
多数浏览器在 **file://**（双击本地文件）下会拦截该请求，页面会显示加载失败。  
请上传到支持 **https** 的静态托管后再访问。

手机浏览器可直接打开；第一次加载稍等节点铺开。可拖动旋转、滚轮/双指缩放、点击节点查看名称与年级。

## 方案 A：腾讯云 EdgeOne Pages（推荐，拖拽即用）

1. 登录腾讯云 → EdgeOne → Pages（或搜索「EdgeOne Pages」）。
2. 新建项目 → 选择「直接上传」/「文件夹上传」。
3. 上传整个 `yanxingzhan-kg/` 目录（保持子目录结构）。
4. 部署完成后打开分配的 `*.pages.dev` 或控制台给出的域名。
5. 验证：
   - `/` 能看到落地页
   - `/viz/` 能旋转 3D（控制台无红色报错）
6. （可选）绑定已备案的自定义域名，便于家长记忆与微信内打开。

## 方案 B：阿里云 OSS 静态网站

1. 新建 Bucket，读写权限按官网「静态网站托管」指引设置（通常公共读）。
2. 开启「静态网站托管」，默认首页填 `index.html`。
3. 用控制台或 ossutil 上传 `yanxingzhan-kg/` 内全部文件，**保持相对路径**。
4. 用 OSS 默认域名或绑定 CDN / 自定义域名（大陆稳定访问建议自定义域名 + 备案）。
5. 打开 `https://你的域名/` 与 `https://你的域名/viz/` 验证。

## 方案 C：其它静态托管

任何支持静态文件的服务均可（又拍云、七牛、自有 Nginx 等）。  
根目录指向本包；无需 Node / PHP / 数据库。

## 关于 Gitee Pages

**Gitee Pages 已下线/不可用**，不要再按「推 Gitee 开 Pages」的老教程操作。  
国内家长访问请用 EdgeOne Pages、OSS+CDN，或其它仍可用的国内静态托管。

## 自定义域名与备案（中国大陆稳定访问）

- 仅用平台临时域名：部分网络/微信内可能不稳定或被提示。
- **自定义域名 + ICP 备案**（若指向中国大陆服务器/加速）：家长访问更稳，也便于放进公众号菜单、视频简介。
- HTTPS 证书：EdgeOne / 阿里云 CDN 均可一键申请。

## 发帖时怎么写链接

- 主 CTA 用国内站：`https://你的域名/` 或 `https://你的域名/viz/`
- **不要**把 github.com / github.io 当作国内家长主入口（常打不开）。
- 本包若尚未上线，文案里可先写「完整网页版即将上国内站」，视频先看效果。
